# TicketBot
半自動搶票工具 目前僅支援 拓元tixcraft、KKTix

( bug很多，對它友善一點，我有時間再慢慢完善

## 使用說明
此工具使用puppeteer腳本控制瀏覽器，ddddocr辨識驗證碼，加速搶票流程，基本上沒有被鎖的風險

不提供同時搶多種票功能，一次僅能搶同一種票且最多4張（依各購票平台限制）

### 第零步
> 在右邊第二項release下載檔案並解壓縮(.zip .rar 擇一)，最上層資料夾提供建立捷徑bat檔`shortcut_builder.bat`，執行後會在原地建立一個捷徑，這個捷徑就是主程式，你想放到哪就放到哪，放到桌面之類的，但原本的資料夾位置就不能移動了，若要移動資料夾，需要重新建立一個捷徑

### 第一步

> 在列表中選擇本次的購票平台
>
> 如誤選平台，請先點擊Stop，再重新開始執行

### 第二步

> 填寫搶票資料，設定皆可為空，代碼空自己點到活動頁面，票數空則為預設*1*，黑、白名單空選擇可選的第一個。
>
> - **活動代碼：**
> 網址中每場活動的特殊代碼
>
> &emsp;&emsp; 拓元：`https://tixcraft.com/activity/detail/26_wte`  ==> **26_wte**
>
> &emsp;&emsp; KK：`https://kktix.com/events/a06dc053/registrations/new`  ==> **a06dc053**
>
>- **購票數量：**
> 就是購票數量，若空白則自動填為‵1‵
>
> - **選區：**
> 可填多個關鍵字，以`，`或是`,`分隔，建議以價錢為主要區分方法
>
> &emsp;&emsp; 若無符合選項則會自動刷新，多次刷新會被平台限制數秒，所以請及時按**暫停**，更改設定後再次按下**繼續**

### 第三步
> 設定完就可以開始執行了，點擊`Start`，而後會自動進入登入頁面，登入完成就結束所有準備流程了，等待活動開放便可以開始搶票

### 第四步
> 在活動開放前數秒**刷新網頁**並點擊`開始搶票`，就可以靜等搶到票了

<br>

### 其他碎碎念
若有需要適當點擊暫停、繼續（與開始搶票同個按鈕）

因為平台一直說不要刷新，而且實際測試不用刷新也可以，所以我沒有把刷新寫進去，但保險起見，還是可以在前1秒按一下刷新

因為是使用ddddocr，而不是專門針對拓元的驗證碼辨識，所以錯誤率很高，但會馬上刷新並重新辨識，還是比自己輸快很多，如果你一直錯誤那是你真的雖，我哪天心情好在自己訓練一個模型

ddddocr.exe 此檔案包了一整個python環境和辨識模型，所以檔案特別大(約150 mb)，不是病毒甚麼的，不用擔心

不要問為甚麼有第零步，所有東西都有它的故事
